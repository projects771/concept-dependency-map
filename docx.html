Project Title Smart USB Device Authentication and Threat Detection System Using Behavioral Machine Learning
Abstract Universal Serial Bus (USB) Human Interface Devices (HIDs) are implicitly trusted by host operating systems upon connection, a design assumption exploited by hardware-spoofing attacks such as BadUSB and USB Rubber Ducky, which disguise malicious microcontrollers as legitimate keyboards or storage devices to perform automated keystroke injection and data exfiltration undetected by conventional antivirus tools. Since spoofed devices can freely forge static identifiers such as VID/PID, descriptor matching alone is insufficient for authentication. This project proposes a Smart USB Device Authentication and Threat Detection System that performs continuous behavioral fingerprinting by jointly profiling static USB descriptors and dynamic operational behavior, including keystroke injection speed (WPM), packet timing jitter, payload entropy, and endpoint request delays, without requiring any hardware modification to peripherals. Features are preprocessed using StandardScaler and LabelEncoder, and classified using Random Forest (primary), Support Vector Machine (SVM), and Gradient Boosting Classifier, trained on 1,500 labeled benign/malicious USB session records. The system targets a classification accuracy exceeding 98%, with strong ROC-AUC and F1-scores and a low false-positive rate, offering a scalable, software-only defense against USB-based hardware spoofing threats.
